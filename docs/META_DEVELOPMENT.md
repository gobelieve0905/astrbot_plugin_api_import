# Meta 操作目录与权限边界

日期：2026-09-14；目标版本：0.1.3。

## 来源与覆盖

`data/meta_operations.json` 由 Meta 官方 `facebook-python-business-sdk` 固定提交 `5286888addfe3ba3718db65fbf132bd66de3ddfe` 的生成类静态提取，SDK v26.0.1，Graph v26.0。1490 个具体请求方法按 `(HTTP method, endpoint)` 合并为 714 个权限项：GET 412、POST 252、DELETE 49、PUT 1。抽象基类的通用请求构造器不是可授权的操作，不导入；SDK 同路由别名不能分别授权。目录包括广告管理和 Business SDK 的相关资产操作，不等于所有未来版本或 SDK 未公开的 Graph API。

再生成：下载固定提交的官方源码后执行 `python tools/build_meta_catalog.py /path/to/facebook-python-business-sdk`。脚本使用 AST，不导入或执行 SDK。审核版本、目录差异、参数类型、路由和许可证后提交；运行时不联网下载目录、不安装 SDK、不探测凭据。官方 SDK 授权原文保留在 `data/META_SDK_LICENSE.txt`。生成脚本及本文从安装归档排除，目录与许可证必须保留。

## 授权

- 单一 `tools_json` 保存所有操作，默认 off；只有 enabled 的操作注册 FunctionTool。各账户 connection.id 隔离，调用名为自定义前缀 + 稳定操作 id。长路由使用稳定摘要后缀，完整调用名不超过 64 字符。
- UI 搜索、方法筛选和批量操作仅改变当前后台表单；保存经过 revision 检查、配置持久化与原子工具替换。没有向 Agent 注册任何管理、解锁、添加或修改配置的工具。
- 后端拒绝改动 Meta 预设的路由、参数 schema 和请求结构；管理员可改名称、凭据、响应设置和开关。实际请求只使用固定 Graph 主机、固定版本、固定方法和路径。
- 固定方法/路径是权限单位。`post_node` 是整个通用对象更新接口，不是单独的预算开关；各 SDK 对象共享相同根路由。它可以更新 Token 有权访问的多类对象。某个具体字段的可写权限仍由 Meta 决定。
- 禁止方法覆盖、外部 Token、ids 多对象封装、通用 Graph batch、字段展开/别名/内嵌查询；字段必须在固定官方目录中，关联字段同时检查对应 GET edge 的开关。`status=DELETED` 还要求 `delete_node`。
- 即便旧工具对象仍在内存中，后台保存成功后也会失效；排队等待并发槽的请求在真正发出前重验工具有效性及权限。已经发往 Meta 的请求无法撤回，也不会因停用而自动补发或回滚。
- 该边界约束本插件发出的请求；不控制管理员另外安装或开放给 Agent 的 Shell、任意 HTTP、MCP 或其他平台工具，也不改变 Meta 侧 Token 的授权范围。

## 请求和返回

SDK 参数映射为 JSON Schema；对象、数组、布尔值使用 JSON 编码后送入查询参数或表单。文件参数接受明确的 base64 字节（单次总量 10 MiB），不接受本地文件路径；更大文件使用官方分片接口。未知字段与参数拒绝；枚举组合和业务必填关系交由 Meta 返回真实校验结果，插件不猜测。

强权限模式禁止包含请求覆盖键或嵌套 fields 的输入。因此部分需要内嵌请求封装的高级接口参数不能直接提交；操作目录可授权不代表任意参数形式都被接受。后续扩展必须先证明不能绕过已关闭的操作，不能增加无约束透传兜底。

分页返回单页与 cursors；不跟随 next URL。输出和保存前移除分页 URL、脱敏 Token/secret/password 等字段，防止凭据进入 Agent 或文件。HTTP 错误和 200 中的 Graph error 均标记失败，写入不自动重试。

大目录将通用配置上限扩为 10000 个工具 / 32 MB，并缓存 schema 合法性检查（缓存不包含 Token）。模型的工具数量和上下文限制不同，请只开启当前需要的操作；714 个操作全部注册可能超过模型厂商限制。

## 本轮验证

本地 59 项单元测试及浏览器检查通过。覆盖完整目录、多接入隔离、权限关闭、旧引用/排队调用失效、参数绕过、请求编码、上传、分页和脱敏；浏览器验证 714 项目录的筛选、隐藏权限保留、后台保存及窄屏。真实 AstrBot 注册/调用/持久化检查由固定提交部署入口的无网络隔离容器执行，随后按既有备份与部署锁流程热加载。不自动调用真实 Meta 广告接口，不发送飞书测试消息。
