# Meta 权限边界检查（API 0.1.3）

日期：2026-09-14。目录基于 Business SDK v26.0.1 / Graph v26.0，固定来源提交 `5286888addfe3ba3718db65fbf132bd66de3ddfe`。

## 结论与保证范围

后台关闭的 Meta **接入账户 + 请求方法/路径**不能通过本插件直接调用。该结论由后端授权检查及模拟传输验证，不依赖模型是否遵循提示词。检测不是对未来 Graph API 行为、所有组合业务效果或整个 Agent 环境的绝对安全保证。

目前服务器没有配置 Meta 接入项，也没有本插件手动配置的 Graph 接口。本次没有执行真实 Meta 查询、写入或发送飞书消息；业务副作用未在真实账户验证。测试使用合成 Token、合成 ID 和 HTTPX MockTransport。

## 授权链路

1. 平台新增默认全部关闭；后台保存使用版本号冲突检查，校验定义后同步更新工具注册表。
2. 只有已启用定义注册成工具；停用/删除/改名/Token 更新成功后，旧工具对象失效。保存失败时保留旧注册表及配置。
3. ImportedTool 在入口检查可用状态；Executor 检查定义 enabled、生命周期和 JSON Schema。
4. Meta prepare 按当前接入 ID、操作 ID 查实时权限，未授权默认拒绝；方法、地址、鉴权和 schema 固定，不接收模型提供的替代路由。
5. 等待并发槽位后，再次检查工具状态、主操作和关联权限。后台更新会取消旧工具正在本地等待的执行任务，包括等待传输连接的任务。
6. 不跟随 HTTP 重定向，不自动重试写入；分页保留游标，不接受服务端 next URL 作为新请求。
7. 管理接口由 Dashboard 鉴权保护，不作为 LLM 工具注册。`/api_test` 使用管理员权限并调用同一个工具入口。

## 本轮发现与修复

| 发现 | 修复 | 影响 |
|---|---|---|
| 批量写入仅验证外层路线，无法证明内部所有子操作都已授权 | 8 个非 GET 且路径包含 batch 的固定目录操作无条件拒绝执行，详情说明限制 | 即使勾选也不会发请求；使用单项接口。批量状态查询不受此限制 |
| POST /copies 可在创建系列/组/广告开关关闭时到达传输层 | 同时要求 post_campaigns、post_adsets、post_ads 授权，排队后复查 | 由于对象类型共享路径，采取保守的全依赖检查 |
| status=DELETED 只检查顶层及无空白写法 | 递归检查结构化参数、去除首尾空白后判断，要求 delete_node | 本地回归证明旧版绕过检查；不宣称所有变体均会被 Meta 接受 |
| 权限在等待连接期间撤销后，原任务仍可能继续 | 跟踪并取消旧工具执行任务；取消结果说明远端状态可能不确定 | 已发送到远端的动作不可撤回，不自动补偿或重试 |

上述四类回归在修复前出现失败，在修复后通过。关联权限排队撤销也纳入回归。

## 必须理解的剩余边界

- **开关不是预算/启停/删除等每项业务能力的独立 ACL。** 当前单位为接入 ID + 方法 + 路径。开启 `post_node` 就允许它定义内的多种对象更新字段；不能推断“另一个创建开关关闭”意味着通用更新绝不影响该资产。SDK 共享对象也不是单独的对象类型权限。
- **同一 Token 可访问多个 Meta 资产。** 模型提供 node_id；插件没有单独的广告账户 ID 白名单。若 Token 能访问多个账户，开启路线覆盖这些可访问对象。后台接入名称不是 Meta 资产隔离策略。
- **远端副作用不能仅凭 HTTP 方法完全枚举。** 新建、更新、复制等已授权操作可能影响关联资产、投放状态或触发任务；本轮保守处理已识别批量与复制边界，不宣称验证了每一个 Meta 参数的所有业务后果。
- **撤销权限不能撤回已发送请求。** 本地任务取消也不证明 Meta 未执行；应核实远端状态。后台关闭后不会自动重新发送。
- **授权以成功保存/应用后的状态为准。** 未保存的页面勾选不影响运行；绕过插件页面直接编辑配置文件需要重载插件。写盘失败返回失败，保留之前的生效授权。
- **本插件不是其他工具的防火墙。** 如果另行给 Agent Shell、任意 HTTP、MCP 或管理凭据，不能靠本插件阻止其他渠道访问 Meta。多个独立接入的权限不会互相覆盖，同 Token 的另一个已授权接入仍可操作。
- **模型仍可能错误选择已授权操作或参数。** 若当前只需查询，应只开启所需 GET 操作，关闭写入、通用对象修改、删除及资产授权相关操作，并给 Token 最小资产/平台权限；这是降低已授权范围内意外行为的配置建议，不是本轮自动改动用户配置。
